The reply advises on a new reporter in a codebase whose reporters receive the options and the logger as constructor
parameters, declared through a static `inject` list of tokens.

PASS if: It has the new reporter receive the framework services it uses (the logger, and the options if it reads any
configuration, such as a configurable output path) the same way: as constructor parameters declared through the
`inject` tokens. It does not have the reporter build them itself, import a global for them, or read the configuration
from somewhere else. A fixed output path with no options injected meets this, since the request names one path.
FAIL if the reply does not meet that, or contradicts it.
