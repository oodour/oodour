The reply advises on a new reporter in a codebase whose reporters receive the options and the logger as constructor
parameters, declared through a static `inject` list of tokens.

PASS if: It has the new reporter receive what it needs (the options, for the output path, and the logger) the same
way: as constructor parameters declared through the `inject` tokens. It does not have the reporter build them itself,
import a global for them, or read the configuration from somewhere else.
FAIL if the reply does not meet that, or contradicts it.
