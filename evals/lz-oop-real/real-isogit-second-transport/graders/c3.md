The reply advises how a JavaScript library should pick between more than one remote transport.

PASS if: It puts the choice of transport in one place (a factory, registry, lookup table or manager) that picks it
from the URL, for example its protocol or scheme, and has the commands ask that place for a transport instead of
naming a transport class themselves.
FAIL if the reply does not meet that, or contradicts it.
