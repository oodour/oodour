# Selector tiers for `@layzee/eslint-plugin-oop`

Measured 2026-11-18 by Claude for Lars's ruling ("1: OK": one rule per `no-restricted-syntax` selector, tier from the
measured false-positive rate on three repositories, too noisy for `strict` means drop, every preset at `error`).

## Method (measured)

- Clones in this folder: lz-gardener `cf9f6f4` (gard), lz-node-test `aa3bc1b` (nt), stryker-playwright-runner `f39d8acd`
  (spr). No install in the clones.
- ESLint 10 and `@typescript-eslint/parser` from the lz-oop main checkout, no type information, only
  `no-restricted-syntax`, one entry per selector, message = the selector's name. Configs: `eslint.config.mjs` (the 44
  selectors as written in `lint/core.md` and `lint/spike/eslint.config.mjs`, listed in `selectors.mjs`) and
  `eslint.sharpened.config.mjs` (the tightened variants in `sharpened.mjs`). Driver `run.mjs`, tally `analyze.mjs`,
  raw output `<repo>-<src|test>[-sharp].json`, tallies `analysis.txt` and `analysis-sharp.txt`.
- Files: every tracked `.ts/.tsx/.mts/.cts/.js/.jsx/.mjs/.cjs`. Skipped: `fixtures/`, `spikes/`, `oss/` (copies of
  upstream harnesses), `dist/`, `*.config.*`, `.d.ts`. Test = `*.test.*`, `*.spec.*`, `*.e2e.*`, any `test/` folder, and
  lz-gardener's `test-*.ts` utilities; the rest is shipped source (src). Files: gard 20 src / 42 test, nt 73 / 131,
  spr 146 / 267. Every run took under 5 s.
- No parse errors in any run (measured: no `fatal` message in the JSON).
- Sampling: up to 6 src hits per selector, spread evenly over the hit list; every hit when there were 10 or fewer, and
  every hit for most sharpened variants. Each sampled hit was read in context against the lz-oop references
  (`smells.md`, `variants-and-conditionals.md`, `dependencies-and-messages.md`, `javascript-and-typescript.md`,
  `judging-design.md`). Verdicts are Claude's judgement (inferred), with the reference rule named.
- Hits column: `src/test` per repository. Tiers are judged on src; test counts are shown because the plugin would turn
  most of these off in test files (see Test files).

Short paths drop the `packages/` prefix; `gs/` stands for lz-gardener's `plugins/lz-gardening/skills/lz-garden/scripts/`.

## Selectors with no hit in any repository

Measured: zero hits in src and test for `switch-true`, `ts-private`, `protected-member`, `arrow-property`,
`super-call-in-method`, `throw-only-override`, `extends-builtin`, `mixin-factory`, `static-method`, `data-class`,
`exported-let`, `entity-method`, `lifecycle-decorator`, `S-new-in-constructor-nonbuiltin`, `S-query-and-command`.

The zeros reflect the code, not broken selectors (measured with `rg` positive controls): the three repositories hold
about six classes outside tests, three of them `extends Error`; no `private` or `protected` keyword; no `switch (true)`;
the only `static` members are `static inject = tokens(...)` fields, which Stryker's plugin API requires and which
`static-method` does not match (it matches methods). The selectors fired on their probe cases in `lint/core.md`.

So these rows have no false-positive rate from this corpus. Provisional tiers (inferred from the selector's precision
and the plugin's rules, not measured): `recommended` for `ts-private`, `extends-builtin`, `mixin-factory`,
`assign-to-prototype`, `switch-true` and `exported-let`, whose every match is a form the plugin rejects outright;
`strict` for `protected-member`, `arrow-property`, `super-call-in-method`, `throw-only-override`, `static-method` and
`data-class`, whose recorded limits in `lint/core.md` already name allowed forms they match; `entity-method` and
`lifecycle-decorator` untested anywhere. A class-heavy corpus would be needed to measure them.

## Test files

Test code holds most of the noise (measured): `boolean-literal-argument` 300 test hits against 31 src, `numeric-index`
272 against 100, `property-chain-3` 203 against 50, `module-let` 30 against 4 (hook state in test files). Every test hit
sampled for the kept rules was acceptable in a test: assertions on a boolean, fakes built with `??`, top-level `let` for
hook state. Inferred: each preset should switch these rules off for test globs, or ship a test override, rather than
raise the false-positive rate for src.

## Limits of this measurement

- Three repositories by one author, mostly functions over classes, so the class-shaped selectors are under-sampled
  (measured: about six classes outside tests). The provisional tiers need a class-heavy corpus.
- Verdicts are one reviewer's reading of the lz-oop references (inferred); no second reviewer checked them.
- Samples of 6 give a coarse rate; rows where every hit was judged say so.
