## Design

- Arm A: main at e3646b4, the plugin text with no person names.
- Arm B: the same text with the names 9c7bcc7 removed put back (`git revert` of 9c7bcc7 in a worktree at
  `D:/tmp/lz-oop-names`; conflicts resolved by keeping today's wording and adding the name where 9c7bcc7 removed it,
  including the moved audit and review skills). A word diff shows only names added: about 40 attributions such as
  "(Sandi Metz)", "(Katrina Owen)", "(Kent Beck)", "(Michael Feathers)", and "based on Sandi Metz's principles and
  practices" in the audit and review skill descriptions. ATTRIBUTION.md is in both arms.
- Suite: all 55 cases of `evals/lz-oop`, split by name into four parts (14, 14, 14, 13), the same split for both arms.
- Models (Lars, 2026-11-25: "Our evals should cover Opus at n=3 and Sonnet at n=5"): `claude plugin eval <part folder>
  --ablation none --model claude-sonnet-5-5 --runs 5` and `--model claude-opus-5-5 --runs 3`, both with
  `--judge-model claude-sonnet-5-5 -j 2 --trust-plugin --no-publish --threshold 0`. No no-plugin baseline: the question
  is A against B. One part on one model per heavy-lock slot (16 slots), arms alternating part by part (A1, B1, A2, B2,
  ...) so drift over the day falls on both.
- A first attempt at Sonnet n=3 was stopped at 09:05 when the run counts changed; a second, at 09:06, ended at once on
  the old 5-hour usage limit (all 70 runs "You've hit your 5-hour limit"); neither produced results.
- Scripts: scratchpad `names-ab/build-parts.ts` (part folders under `D:/tmp/lz-oop-names-eval/<arm>-p<n>`) and
  `names-ab/run-part.sh`. Results: `D:/tmp/lz-oop-names-eval/<arm>-p<n>/result.json` and the eval's own results folder.

- A slot ended at 09:35 before part A1 on Sonnet finished; `claude plugin eval` writes its JSON only at the end, so
  nothing was kept. The script now runs one case per eval call (`--case`) and keeps each case's JSON, so a slot end
  keeps the finished cases and the next slot for the part resumes with the rest. Comparison: scratchpad
  `names-ab/compare.ts` (paired per-case mean scores, B - A with a 95% bootstrap interval over cases, Pass@k, Pass^k,
  run errors, cost).
- Measured on the first case (audit-hot-spots, Sonnet 5.5, 5 runs): 117 s and $1.34. At that rate a 14-case part on
  Sonnet takes about 27 minutes, and the whole A/B (both arms, both models) costs roughly $300 to $350 (inferred from
  one case).
